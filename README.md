This project uses Playwright to perform automated tests for a login feature and a user update feature. 
Playwright is a JavaScript-based end-to-end testing framework that allows developers to write execute tests in a real browser.

## Installation

```bash
npm install

```

>**NOTE**
>
>It is necessary to have **node** installed

## Running
``` bash
#You open the playwright UI
npx playwright test --ui

Click on the Play button or press F5 to run the tests
```
